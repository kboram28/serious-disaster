출처: `한국산업안전보건공단_산업재해 고위험요인(SIF) 조회서비스_오픈API 활용가이드_260828_v1.0.hwp`
확인일: 2026-10-20 (실제 호출로 검증)

## 호출

```
GET https://apis.data.go.kr/B552468/sifArchive/view
```

| 파라미터 | 값 | 비고 |
|---|---|---|
| `serviceKey` | `.env`의 `DATA_GO_KR_KEY` (Decoding 키) | requests가 자동 인코딩 |
| `callApiId` | `1170` | 고정값 (가이드에 명시) |
| `cateSeCd` | `1` = 전업종(건설업 외), `0` = 건설업 | 가이드에는 `1`만 나옴. `0`은 호출로 확인 |
| `disasterOverview` | 검색어 (필수, 빈 값 불가) | **`%` 를 넣으면 전체 조회** |
| `pageNo` | 1부터 | 필수 |
| `numOfRows` | 페이지당 건수 | 필수 |

- 초당 최대 30건(30 tps), 개발계정 트래픽 1,000회
- 가이드의 예제 URL에는 `/view`가 빠져 있으나 실제로는 `/view`가 필요함
