## 동작 구조

```
질문 → 동의어 사전으로 업종(8개)·재해유형(6개) 키워드 찾기
     → 엑셀에서 업종 AND 재해유형으로 필터 → 앞에서 최대 5건
     → 사례 + 예방대책을 넣고 "이 정보를 간단히 요약해 주세요" → GPT (대화 이력 포함)
```

## 실행을 위해 바꾼 것 (원본과 다른 곳은 이 4곳뿐)

| # | 원본 | 바꾼 것 | 이유 |
|---|---|---|---|
| 1 | API 키를 코드에 직접 작성 | `.env`의 `OPENAI_API_KEY`에서 읽음 | 키 보호 |
| 2 | 엑셀 경로가 작성자 PC의 절대 경로 | `views.py`와 같은 폴더 | 다른 PC에서 서버 시작 시 오류 |
| 3 | 텍스트 질문을 JSON으로만 읽음 | FormData·JSON 둘 다 처리 | 화면은 FormData로 보냄. 졸업작품 당시 고쳤으나 고치기 전 파일만 남아 다시 수정 |
| 4 | 모델 `gpt-4-turbo` | `gpt-4.1-mini` | 원본 모델 서비스 종료 (2026-11-19 호출 시 deprecated 오류, `screenshots/1_model_deprecated.png`) → 같은 계열 모델로 교체해 테스트 |

## 실행 확인 (2026-11-19, `screenshots/2_run_and_bug.png`)

| 질문 | 결과 |
|---|---|
| "건설업 추락 사고" | 사전에 있는 단어 → 건설업·떨어짐 사례를 요약하고 예방대책 정리 |
| "사다리에 올라 배관 설치하다 떨어졌어요" | 업종 단어가 사전에 없음 → `map_synonyms`가 **문장 전체를 업종으로 반환** → 사례 0건 → "'사다리에 올라 배관 설치하다 떨어졌어요' 업종에서 … 정보가 없습니다" |

→ 사전에 없는 표현으로 물으면 사례를 찾지 못하고, "질문에서 업종이나 사고 유형을 확인할 수 없습니다" 안내도 사실상 나오지 않는다.
